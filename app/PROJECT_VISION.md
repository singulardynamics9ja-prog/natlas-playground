# N-ATLAS Playground

## Problem

Many developers, students, founders, and researchers need an easy way to test and evaluate N-ATLAS for real-world use cases.

## Solution

N-ATLAS Playground is a developer infrastructure platform that provides prompt testing, multilingual experimentation, reusable prompt templates, and AI evaluation tools for N-ATLAS.

## Supported Languages

- English
- Yoruba
- Hausa
- Igbo

## Target Users

- Developers
- Students
- Researchers
- Startups
- SMEs

## Current Features

- Landing Page
- Chat Playground
- Prompt Templates
- Language Selection
- Timestamps
- Typing Indicator
- New Chat

## Planned Features

- Supabase Database
- User Accounts
- Feedback System
- Analytics Dashboard
- Real N-ATLAS API Integration
